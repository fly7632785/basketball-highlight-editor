# BHE 移动端页面设计稿

这组设计稿按桌面端现有功能拆分，视觉使用桌面版 BHE 的颜色、字体和控件语义。

## 页面顺序

1. 项目首页：新建、打开、当前项目统计、最近项目、工作流
2. 导入视频：视频信息、文件大小、耗时预估、基础信息确认
3. 分析配置：分析范围、篮筐/篮网区域、分析质量、片段时长
4. 分析进度：阶段、进度、耗时、预计剩余、帧数、暂停/取消/恢复
5. 审核工作台：视频优先、原视频切换、候选缩略图、保留/排除、撤销、标签、算法证据
6. 导出集锦：分片/合并导出、球员筛选、进度、取消、重试、历史
7. 设置与反馈：主题、语言、存储、自动保存、反馈邮箱、关于 BHE
