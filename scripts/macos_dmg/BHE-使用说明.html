BHE macOS 使用说明

当前版本是 Ad Hoc 签名的测试版，未做 Apple 公证，首次打开会被拦截——这是正常现象，不是软件损坏。

方法一：一条命令解决（最稳，推荐）
  1. 按 Command + 空格，输入“终端”或"Terminal"，回车打开；
  2. 把下面这条命令粘贴进去，按回车；
  3. BHE 会自动安装、解除拦截并启动。
ditto "/Volumes/BHE/BHE.app" "$HOME/Applications/BHE.app" 2>/dev/null || ditto "/Volumes/BHE/BHE.app" /Applications/BHE.app; xattr -rd com.apple.quarantine /Applications/BHE.app "$HOME/Applications/BHE.app" 2>/dev/null; open -a BHE
方法二：右键打开（最快，多数情况够用）
把 BHE.app 拖到旁边的"Applications"图标中，然后在"应用程序"里的 BHE 上按住 Control 点击（或右键）→ 打开 → 再点"打开"。只需一次，之后可正常双击启动。
方法三：一键修复命令（若系统允许运行）
双击 BHE-首次打开修复.command，自动完成安装、清拦截和启动。双击它时如果也弹"无法验证"，同样右键 → 打开；右键也不行，就用上面的方法一。

以上操作只处理 BHE.app，不会上传视频或访问外部服务。如果提示"应用已损坏"，说明下载不完整，请重新下载 DMG。彻底消除这些提示需要 Apple Developer ID 签名和公证，属于正式发布阶段的工作。
