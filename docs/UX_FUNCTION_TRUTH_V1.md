# Courtside 功能真相与 UI 约束 V1

> 本文档是 Courtside（篮球高光视频助手）的产品功能真相。
>
> 用途：
> 1. 记录当前桌面端真实页面、按钮、文案、弹框、菜单、状态和交互；
> 2. 作为 UI 重设计、视觉优化和后续实现的不可违背约束；
> 3. 防止设计工具或后续 Agent 自行增加流程、删除功能或修改按钮语义。
>
> 范围：macOS/Windows 优先的 Flutter 桌面端 V1。当前产品是本地固定机位篮球视频的“自动生成候选 + 人工审核 + 导出”工具，不是无人值守的自动剪辑器。

## 1. 产品初衷

### 1.1 用户问题

篮球比赛固定机位视频通常很长，用户想快速获得自己的投篮、进球或比赛高光，但不希望：

- 手动从头到尾观看整场视频；
- 把原始视频上传云端；
- 为了一个片段进入复杂的专业剪辑流程；
- 因为算法误检而失去对最终结果的控制。

### 1.2 产品承诺

Courtside 的核心承诺是：

> **把整场比赛，变成你的高光。**

产品通过本地分析快速缩小搜索范围，生成“疑似高光候选”，再让用户在视频审核工作台中快速确认、排除、调整和导出。

### 1.3 产品边界

| 项目 | V1 约束 |
|---|---|
| 输入 | 单项目、单视频、单篮筐、固定机位 |
| 算法目标 | 高召回生成候选，不宣称 100% 自动判断 |
| 审核 | 候选默认保留，用户主要剔除误检；也支持确认、备注、调整范围和手动新增 |
| 输出 | 未排除候选，支持合并导出和分别导出 |
| 隐私 | 本地处理，不登录，不自动上传，原始视频只保存引用路径，不复制原视频 |
| 平台 | macOS 优先，Windows 保持架构兼容 |
| 后续不属于 V1 | 多视频、多篮筐、多机位、云同步、移动端重型分析、自动上传训练数据 |

## 2. 设计主题

### 2.1 主题名称

**Quiet Courtside Control Room（安静的场边控制室）**

这是一个长时间使用的桌面工具，视觉应该像专业但易懂的本地视频工作台：安静、稳定、精确、低干扰。

### 2.2 视觉关键词

- 视频优先（Video-first）
- 自动优先、人工覆盖（Automatic-first, manual override）
- 高信息密度但不拥挤
- 深色工作台、清晰分区、低饱和状态色
- 键盘友好、鼠标友好
- macOS 桌面工具感，而不是营销页面
- 所有常规审核动作尽量就地完成，不使用居中弹框打断流程

### 2.3 视觉层级

1. 当前视频画面是第一视觉焦点；
2. 当前候选的时间范围、时长和审核状态是第二焦点；
3. 候选列表、球员标签和证据是第三焦点；
4. 分析耗时、引擎状态、导出历史等属于辅助信息。

### 2.4 颜色语义

颜色不能成为唯一的状态表达方式，必须同时使用文字、图标、边框或位置表达。

| 语义 | 建议表现 | 用途 |
|---|---|---|
| 主操作/当前选中 | 靛蓝/蓝色 + 细边框 | 当前候选、主要 CTA、焦点状态 |
| 分析注意 | 橙色/琥珀色 | 快速模式风险、较大视频、可恢复任务 |
| 保留/确认 | 绿色 | 保留、确认、完成 |
| 排除 | 灰色降低对比度，可配红色提示 | 已排除候选、不可导出候选 |
| 错误 | 红色 | 分析失败、视频加载失败、目录打开失败 |
| 中性 | 深灰层级 | 面板、分隔线、未激活控件 |

### 2.5 排版与间距

- 中文优先使用系统无衬线字体；技术时间码、路径和耗时使用等宽数字。
- 基础间距使用 4px/8px 节奏，常用面板内边距 12px/16px。
- 主标题不应压过视频和审核任务；避免巨型 Hero。
- 时间码必须使用 tabular figures，避免不同数字宽度导致跳动。
- 保留足够的可点击面积；图标可以小，但点击区域不能过小。

### 2.6 动效原则

允许加入适合工具场景的简约动效，但不能改变功能或拖慢审核：

- 页面/步骤切换：150–220ms 淡入或轻微位移；
- 候选选中：150–200ms 背景和边框过渡；
- 分析/导出进度：平滑进度变化，不使用夸张数字跳动；
- 加载：优先骨架、细进度条或轻量旋转，不遮挡主要任务；
- 状态完成：一次短暂的图标/颜色反馈；
- 菜单/锚定弹出：100–160ms 淡入/缩放，保持定位稳定；
- 禁止：自动播放装饰视频、持续闪烁、弹跳、布局位移、营销式粒子效果；
- 支持 reduced motion（减少动态）偏好。

## 3. 全局应用壳

### 3.1 四个主页面

路由和导航顺序固定：

| 顺序 | 页面 | 导航文案 | 主要任务 |
|---:|---|---|---|
| 0 | Home | 项目 | 新建/打开项目，查看最近项目和总体进度 |
| 1 | Import | 导入 | 选择视频、设置分析范围、设置检测区域、选择分析模式 |
| 2 | Review | 审核 | 播放视频、审核候选、修改候选、决定导出范围 |
| 3 | Export | 导出 | 选择导出方式和范围，查看进度与历史 |

### 3.2 宽窗口与窄窗口

- 宽窗口：左侧导航栏 + 顶部条 + 页面内容；
- 窄窗口：顶部条 + 页面内容 + 底部导航；
- 审核页宽窗口保持“视频区 + 候选区”并排；窄窗口按“视频 → 候选列表”上下堆叠；
- 不允许出现横向溢出；不因装饰元素挤压视频和候选主任务。

### 3.3 侧栏

宽窗口侧栏支持展开和收缩：

- 展开：显示 `Courtside`、图标和文字；
- 收缩：保留图标，悬停显示 Tooltip；
- 导航项：`项目`、`导入`、`审核`、`导出`；
- 底部工具项：`反馈`、`关于`；
- 底部隐私徽章：`本地处理`；
- 当前页面必须有明确选中态；
- 不增加左侧导航项，不把页面内部功能搬到侧栏。

### 3.4 顶部条

当前页面顶部显示：

- 当前分支标题：`项目` / `导入` / `审核` / `导出`；
- Engine 状态胶囊：`Engine 就绪`、`等待 Engine`、`Engine 未启动`、`Engine 错误`；
- 非项目首页显示 `关闭当前项目`；
- 宽窗口显示 `本地处理` 和盾牌图标；
- `更多`菜单；
- `切换主题`按钮：跟随系统 → 浅色 → 深色 → 跟随系统。

### 3.5 全局“更多”菜单

菜单项固定为：

- `反馈`：打开默认邮件客户端；失败时显示 `未找到可用的邮件客户端，请手动联系反馈邮箱。`；
- `关于 Courtside`：打开关于弹框。

### 3.6 关闭当前项目弹框

无任务时：

- 标题：`关闭当前项目？`
- 内容：`项目数据和原始视频会保留，下次可以从项目列表重新打开。`
- 按钮：`返回`、`关闭项目`

有分析/导出任务时：

- 标题：`任务仍在进行`
- 内容：`关闭项目会先取消当前任务，项目数据和原始视频不会被删除。`
- 按钮：`返回`、`取消任务并关闭`

### 3.7 退出软件弹框

无任务时：

- 标题：`退出 Courtside？`
- 内容：`确认关闭软件吗？本地项目数据不会被删除。`
- 按钮：`返回`、`退出软件`

有任务时：

- 标题：`任务仍在进行`
- 内容：`当前任务还在进行，退出前需要先取消任务。`
- 按钮：`返回`、`取消任务并退出`

## 4. 项目页（Home）

### 4.1 页面目的

作为项目入口，帮助用户快速：

1. 新建项目；
2. 打开已有项目；
3. 继续最近项目；
4. 了解当前保留数、排除数和视频时长；
5. 看到导入→分析→审核→导出的整体进度。

### 4.2 固定文案和操作

页面标题区：

- 标题：`把整场比赛，变成你的高光。`
- 说明：`导入固定机位视频，本地分析候选进球，剔除误检后导出集锦。所有处理在本机完成，原始视频不会被复制或上传。`

主卡片：

- 标题：`从视频开始`
- 说明：`选择一段固定机位录像，系统会优先自动定位篮筐，随后生成候选进球片段供你审核与导出。`
- 主按钮：`新建项目`
- 次按钮：`打开项目`

当前项目指标：

- `当前项目`
- `当前保留`
- `已排除`
- `视频时长`
- 辅助说明：`本地 SQLite · 原始视频不复制`

最近项目：

- 标题：`最近项目`
- 刷新 Tooltip：`刷新最近项目`
- 项目卡显示：项目名、视频名、保留数、候选数、视频时长；
- 项目卡可点击打开；
- 删除 Tooltip：`删除项目`。

### 4.3 Home 状态

- 首次加载：项目卡骨架；
- 没有项目：标题 `还没有项目`，说明 `新建一个项目后，分析记录和导出历史会显示在这里。`，按钮 `新建项目`；
- 加载失败：标题 `加载最近项目失败`，说明显示错误信息，仍允许重试；
- 有项目：显示最近项目网格；
- 忙碌时：新建、打开、删除和刷新等操作按现有逻辑禁用。

### 4.4 删除项目弹框

- 标题：`删除项目？`
- 内容：`将删除“{项目名}”的项目数据库、分析缓存和导出文件，原始视频不会被删除。`
- 按钮：`取消`、`删除项目`
- 这是破坏性操作，视觉上应明确但不能误导用户删除原始视频。

## 5. 导入页（Import）

### 5.1 页面目的

这是一个四步配置向导。编辑先进入本地 `workflowDraft`，最后点击确认才应用配置并启动分析。

页面标题：`配置分析项目`

有视频时说明：`按步骤确认视频、分析范围和篮筐检测区域，最后再开始分析。`

无视频时说明：`先选择一段固定机位视频，系统会在最后一步统一应用配置。`

顶部按钮：`更换视频`（有视频时显示）。

四步指示器固定为：

1. `01 选择视频`
2. `02 分析范围`
3. `03 检测区域`
4. `04 确认并分析`

已完成的前置步骤可以点击返回；忙碌时不能编辑。

底部导航固定为：

- `上一步`
- `下一步`
- 最后一步：`确认配置并开始分析`

### 5.2 未完成草稿提示

检测到草稿时显示：

- `检测到上次未完成的配置。`
- `放弃草稿`
- `继续配置`

交互：

- `继续配置`：关闭提示，恢复草稿步骤和参数；
- `放弃草稿`：清除草稿，回到当前视频的默认配置；
- 不允许设计成强制重新开始。

### 5.3 第一步：选择视频

无视频状态：

- 标题：`选择原始视频`
- 说明：`支持 MP4、MOV、M4V、AVI、MKV。原始视频不会被修改或上传。`
- 按钮：`选择视频`

选择后显示：

- 标题：`视频已准备好`
- 视频文件名和元数据；
- 处理提示：视频大小、分辨率和预计处理风险。

支持格式：MP4、MOV、M4V、AVI、MKV。

#### 大视频提醒弹框

当视频体量、分辨率、码率或时长较大时显示：

- 标题：`这个视频可能需要较长时间`
- 内容：动态视频风险说明 + `如果方便，建议先用剪辑工具压缩后再导入。也可以继续，原视频不会被修改。`
- 按钮：`先取消`、`继续导入`

取消后回到选择视频步骤；继续不会修改原视频。

### 5.4 第二步：分析范围

- 标题：`分析范围`
- 说明：`默认分析全片。拖动范围手柄排除热身、暂停或比赛结束部分，修改会自动保存在当前草稿。`
- 视频时间轴支持播放/暂停、拖动范围两端、查看当前播放位置；
- 按钮：`使用全片`；
- 时间码、范围和进度必须稳定，不因数字变化造成布局跳动。

### 5.5 第三步：检测区域

- 标题：`检测区域`
- 说明：`系统会先自动识别篮筐。橙色区域用于球轨迹，白色区域只覆盖篮网摆动范围；拖动或缩放后会自动保存到草稿。`
- 画布显示视频预览和 ROI（感兴趣区域）；
- 橙色区域：`投篮分析区`；
- 白色区域：`篮网检测区`；
- 切换按钮：`投篮分析区`、`篮网检测区`；
- 操作按钮：`重置篮网区`；
- 当前编辑投篮区说明：`当前编辑橙色投篮分析区域：覆盖来球轨迹、篮圈和篮网下方的落球范围。`
- 当前编辑篮网区说明：`当前编辑白色篮网区域：覆盖篮圈下方到网底，尽量不要包含篮板、球员或地面。`
- 支持拖动、缩放、适应画面；Tooltip：`缩小`、`放大`、`适应画面`；
- 自动识别中显示：`正在自动识别篮筐…`；
- 预览不可用时保留 `生成预览` / `重新生成预览` 等现有状态引导。

### 5.6 第四步：确认配置

标题：`确认配置`

说明：`确认后保存检测区域并开始分析；已有候选将被当前配置替换。`

摘要字段：

- `视频`
- `分析范围`
- `投篮分析区`：`未设置` / `已设置`
- `篮网检测区`：`自动推荐` / `已设置`

分析模式（快速模式功能开关打开时显示）：

- `标准分析`
- `快速分析`
- 快速模式说明：`快速分析使用低规格代理，可能漏检少量片段。`
- 首次默认标准；模式按项目记忆；不能把快速模式误写成更准确。

耗时提示：

- `开始前预计耗时：约 X–Y 分钟`
- `实际耗时会受视频编码、磁盘和设备负载影响。`

#### 已有候选确认弹框

当当前项目已有候选时显示：

- 标题：`应用新配置？`
- 内容：`当前已有 {N} 个候选片段。应用后会按新配置重新生成候选，原始视频不会被删除。`
- 按钮：`取消`、`应用并重新分析`

确认后应用草稿、启动分析并进入审核页；取消则保留当前配置。

### 5.7 导入页任务反馈

- 忙碌时显示细进度/状态和 `state.busyMessage`；
- 不允许同时启动第二个重型任务；
- 不能通过静态“等待中”掩盖真实阶段；
- 页面切换使用轻量 AnimatedSwitcher，不能导致按钮位置大幅跳动。

## 6. 审核页（Review）

### 6.1 页面目的

审核页是产品的核心工作台，目标是让用户快速完成：

1. 看当前视频；
2. 选择候选；
3. 播放候选或原视频上下文；
4. 保留/排除；
5. 修改球员、片段范围和备注；
6. 必要时使用“补漏”加入片段；
7. 进入导出。

候选默认保留，用户不需要逐条点击确认才能导出；主要动作是排除误检。审核动作不能被多余弹框打断。

### 6.2 审核页大布局（必须保留）

宽窗口：

```text
左：视频工作区（主区域） | 右：候选片段栏（独立滚动）
视频下方：进度/播放控制 + 当前候选证据与编辑操作
```

窄窗口：

```text
视频工作区
候选片段栏
```

禁止：

- 不增加新的左侧导航；
- 不把候选列表改成全屏流程；
- 不把常规球员选择、保留、排除变成居中弹框；
- 不增加“审核确认”“保存审核”“下一步审核”等额外步骤；
- 不把视频控件全部漂浮到视频中央。

### 6.3 分析状态栏

分析中显示：

- 标题：`正在分析视频`
- 阶段 + 百分比，例如：`快速扫描候选 · 35%`
- 状态：`分析进行中`
- 已用时间，必要时显示剩余估算；
- 按钮：`取消`、`重试分析`、`重新分析`（按状态出现）。

失败显示：

- 标题：`分析失败`
- 错误信息或 `请检查视频后重试`；
- `重试分析`。

中断/可恢复显示：

- 标题：`上次分析没有完成`
- 说明：`已有候选可以继续使用，也可以重新分析`；
- `重试分析` / `重新分析`。

完成显示：

- 标准模式：`标准分析 · {N} 个候选 · 用时 {时长}`；
- 快速模式：`快速分析 · 可能漏检 · {N} 个候选 · 用时 {时长}`；
- 有阶段详情时显示代理、粗扫、精筛、缓存命中等耗时信息。

分析新批次成功前，旧候选不能被半成品结果清空；分析完成前不允许导出新结果。

### 6.4 视频工作区

视频源：

- 默认使用原视频进行审核；
- 若存在审核代理/预览源，允许在原视频与审核源之间切换；
- 原视频/审核源切换按钮必须明确当前来源；
- 打开审核页默认不自动播放；
- 切换视频源或候选时可自动播放当前候选，这是现有交互约定；
- 没有视频：`还没有视频`；
- 视频尚未准备：`分析完成后会在这里预览候选片段，点击播放开始`；
- 加载失败：`视频加载失败`，按钮 `重新加载视频`。

视频画面内允许保留：

- 当前已有的播放/暂停中心按钮；
- 标注开关；
- 视频源切换；

不增加装饰性浮层或持续播放动画。

### 6.5 播放控制区

控制区固定在视频下方，包含：

- 进度条/可拖动 Slider；
- 原视频标记：`原视频`；
- 候选标记：`候选 00:12` 等；
- 当前时间 / 当前片段时长；
- 播放速度：`1×`、`1.25×`、`1.5×`、`2×`；
- 上一个候选 Tooltip：`上一个候选 (↑)`；
- 播放/暂停 Tooltip：`播放 (Space)` / `暂停 (Space)`；
- 下一个候选 Tooltip：`下一个候选 (↓)`；
- 重播 Tooltip：`重播当前片段 (R)`；
- 循环 Tooltip：`循环当前片段 (L)` / `关闭循环播放 (L)`。

快捷键以当前代码为准：

| 快捷键 | 动作 |
|---|---|
| `Space` | 播放/暂停 |
| `↑ / ↓` | 上一个/下一个候选 |
| `← / →` | 在当前时间轴中快退/快进 2 秒 |
| `R` | 重播当前候选 |
| `L` | 循环当前候选 |
| `A` | 显示/关闭标注 |
| `C` / `Enter` | 保留当前候选 |
| `X` / `Backspace` | 排除当前候选 |
| `Cmd/Ctrl+Z` | 撤销上一次审核 |

### 6.6 当前候选证据与编辑区

视频下方显示当前候选的紧凑信息：

- `候选 00:12`
- `片段 00:06 - 00:15 · 时长 9 秒`
- `备注`：无备注显示 `—`；
- `候选置信度`；
- `轨迹穿框`：`通过` / `推定穿框` / `未通过` / `—`；
- `篮网运动`：`明显` / `有运动` / `信号较弱` / `—`；
- `反弹判断`：`检测到` / `未发现` / `—`；
- `系统说明`：例如 `证据不确定`、`可能擦框/弹出`；
- Tooltip 解释证据含义，不能把辅助证据包装成确定事实。

操作按钮：

- Tooltip：`调整片段范围`；
- Tooltip：`编辑备注`；
- Tooltip：`撤销上一次审核 (Cmd/Ctrl+Z)`。

### 6.7 候选片段栏

标题和摘要：

- 标题：`候选片段`
- 计数：`已选 {includedCount} / {totalCount}`

工具栏：

- 批量按钮 Tooltip：`批量选择候选`；批量状态 Tooltip：`退出批量选择`；
- 过滤按钮 Tooltip：`筛选候选`；
- 快捷键 Tooltip 内容固定为：

```text
快捷键
Space  播放/暂停
R  重播当前
L  循环当前
A  显示/关闭标注
↑ / ↓  切换候选
← / →  快退/快进 2 秒
C / Enter  保留
X / Backspace  排除
Cmd/Ctrl+Z  撤销
```

筛选菜单固定项：

- `全部候选`
- `待审核`
- `已确认`
- `已排除`
- `低置信度`

批量选择时：

- 显示 `批量 {N} 个`；
- 显示批量球员设置入口；
- 可以为选中候选统一设置球员或清除球员；
- 可以批量保留/排除；
- 工具栏只在批量模式和有选中项时显示相关操作；
- 不改变单候选点击播放和审核行为。

### 6.8 候选行

每行必须保留以下信息和交互：

- 缩略图；
- 序号和事件时间，例如 `#1 00:12`；
- 实际片段起止时间和真实时长，例如 `00:06 - 00:15`、`时长 9 秒`；
- 球员标签；
- 候选状态/置信度信息；
- 保留按钮 Tooltip：`保留片段 (C / Enter)`；
- 排除按钮 Tooltip：`排除片段 (X / Backspace)`；
- 点击行切换当前候选并更新视频；
- 点击保留/排除按钮不能意外切换当前选中候选；
- 排除候选降低显示权重，但仍可通过 `已排除` 筛选找到；
- 当前选中候选必须有明确但克制的选中态。

### 6.9 球员标签

球员标签必须是行内锚定菜单，不使用居中选择弹框。

点击标签后显示：

- 搜索框 Placeholder：`搜索球员`；
- `未标记`；
- 已有球员列表；
- `新建球员`。

交互：

- 选择已有球员后立即写入当前候选；
- 选择 `未标记` 清除球员；
- 选择 `新建球员` 才打开添加球员文本弹框；
- 菜单锚定在球员标签附近，不能出现在屏幕中央；
- 菜单不能被候选栏裁切；
- 批量设置可使用底部菜单/就地菜单，但不能把单个球员选择改回中心弹框。

#### 添加球员弹框

- 标题：`添加球员`
- 输入提示：`例如：科比、罗斯`
- 按钮：`取消`、`添加`
- 空名称不提交。

### 6.10 调整片段范围弹框

这是少数允许使用居中弹框的编辑任务，因为它需要更大的视频和时间轴空间。

- 标题：`调整片段范围`
- 说明：`拖动时间轴两端即可调整。视频会跳到正在拖动的一端；原视频不会被修改。`
- 显示视频预览；
- 播放/暂停；
- `当前位置 00:00`；
- `片段 00:06 - 00:15 · 9 秒`；
- RangeSlider 两端可拖动；
- `恢复默认`；
- `取消`；
- `应用`。

### 6.11 候选备注弹框

- 标题：`候选备注`
- Placeholder：`例如：补篮、擦框、镜头遮挡`
- 支持多行；
- 按钮：`取消`、`保存`；
- 保存后立即回到审核工作台，不改变当前候选选择。

### 6.12 重新分析弹框

普通重新分析：

- 标题：`重新分析当前视频？`
- 内容：`重新分析会替换当前候选列表，但不会删除原始视频。`
- 按钮：`取消`、`重新分析`

快速模式结果建议切标准模式时：

- 内容：`快速分析可能漏检，建议改用标准模式重新分析。当前候选会在新结果成功后替换，原始视频不会被删除。`
- 按钮：`取消`、`用标准模式重新分析`

### 6.13 审核空状态

必须保留按原因区分的引导：

- 恢复中：`正在恢复项目` / `正在加载候选片段和审核记录。`
- 恢复失败：`项目数据加载失败` / `候选片段没有成功恢复，请重试加载，不需要重新分析视频。` / `重试加载`
- 分析中：`正在等待候选片段` / `分析完成后会显示候选片段。`
- 筛选无结果：`没有匹配的候选` / `当前筛选条件下没有片段。` / `显示全部`
- 快速模式空结果：`快速分析未找到候选 · 可能漏检` / `用标准模式重新分析`
- 没有分析结果：`还没有分析结果` / `重新分析` 或 `去导入视频`
- 有视频但无候选：说明返回重新分析或重新配置。

底部操作：

- 主按钮：`导出 {N} 个片段`
- 辅助 Tooltip：`重新配置分析区域和范围`
- 辅助 Tooltip：`重新分析当前视频`

只有未排除候选大于 0、没有分析/导出锁定时，导出按钮可用。

### 6.14 补漏候选

该功能必须保留，即使视觉设计中不显眼：

- 用户在原视频中定位到漏检事件；
- 从原视频当前播放位置触发 `补漏`；
- 打开片段范围编辑器；
- 用户调整起止时间并保存；
- 补漏片段标记为手动候选，默认保留并进入导出；
- 用户仍可以排除、备注、调整和导出；
- 不能因为“自动优先”而隐藏人工补录能力。

## 7. 导出页（Export）

### 7.1 页面目的

只导出当前未排除的候选。导出页允许用户按球员筛选、选择合并/分别导出、观察进度、取消/重试，并查看导出历史。

页面固定文案：

- 标题：`导出集锦`
- 说明：`分析结果默认保留，导出时只排除你打叉的片段。`

### 7.2 汇总卡片

- `当前保留`：`N 个`
- `合计时长`：时间码
- `输出编码`：`H.264 / AAC`
- `处理方式`：`硬件编码优先，软件回退`

### 7.3 导出范围筛选

有球员时显示：

- 标题：`导出范围`
- `全部球员`
- 每个球员名称；
- `未标记`
- 当前摘要：`当前筛选：{N} 个 · {时长}`

筛选只影响本次导出，不修改候选审核状态。

### 7.4 快速模式风险提示

快速模式结果显示：

`当前结果来自快速分析，可能漏检；如需更完整结果，建议先用标准模式重新分析。`

Tooltip：`关闭提示`。

### 7.5 导出任务状态

导出中显示阶段：

- `准备导出`
- `生成片段`
- `合并片段`
- `保存导出记录`

同时显示百分比和：

`本次输出使用启动导出时的片段列表，之后的审核修改用于下一次导出。`

按钮：`取消导出`。

导出中提示：

`导出任务在后台运行，返回审核后仍可继续修改候选。`

分析仍在进行时：

`视频仍在分析，分析完成后才能导出新的候选结果。`

导出中断时：

- `上次导出已中断，可以从原设置重新导出。`
- `重试导出`

### 7.6 导出动作

- 主按钮：`合并导出`；打开文件保存位置，建议名 `highlights.mp4`；
- 次按钮：`分别导出`；选择输出目录，确认按钮 `选择输出目录`；
- 只有当前保留数大于 0 且没有冲突任务时可用；
- 导出完成后不能锁死审核区，用户可以返回继续修改。

### 7.7 导出后说明与返回

- 说明：`导出会包含所有当前保留的候选；已排除片段不会进入输出。`
- 按钮：`返回审核`

### 7.8 最近导出

有记录时：

- 标题：`最近导出`
- 每条记录显示：合并/分别导出、片段数、总时长、输出路径、创建时间、处理耗时、文件大小、分辨率、视频编码、音频编码；
- 按钮：`打开目录`。

无记录时：

- 标题：`还没有导出记录`
- 说明：`完成一次导出后，历史记录会出现在这里。`

打开目录失败弹框：

- 标题：`无法打开目录`
- 内容：目录路径 + 系统错误信息；
- 按钮：`知道了`。

## 9. 全局状态与不可变交互规则

### 9.1 状态

设计必须覆盖以下状态：

- 空项目
- 正在加载
- 视频已选择
- 视频缺失
- 自动 ROI 识别中
- 草稿恢复
- 分析排队/进行中/完成/失败/取消/可恢复
- 候选加载中/有候选/无候选/筛选无结果
- 视频加载中/播放/暂停/错误
- 审核候选待审核/已确认/已排除
- 导出排队/进行中/完成/失败/取消/可恢复
- Engine 就绪/等待/未启动/错误
- 窄窗口和侧栏收缩

### 9.2 不能改变的功能契约

1. 不能删除任何现有按钮、Tooltip、菜单项或状态提示；
2. 不能改变按钮文案的语义；
3. 不能把 `保留` 改成强制确认流程；
4. 不能把 `排除` 改成删除候选；
5. 不能把 `未标记` 和 `未确认` 混为一谈；
6. 不能把候选时间和视频总时长混成一个概念；
7. 不能将球员菜单改成居中例行弹框；
8. 不能让导出后审核区不可编辑；
9. 不能隐藏补漏候选能力；
10. 不能在分析或导出过程中伪装成无事发生；
11. 不能把本地处理、原视频不上传的产品承诺弱化或改写成云端流程；
12. 不能增加左侧导航、额外工作流页面或营销模块。
