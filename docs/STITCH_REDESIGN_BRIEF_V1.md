# Courtside Stitch 保功能重设计简报 V1

> 这是给 Stitch 的设计输入，不是自由创作 brief。
> Stitch 可以重做视觉、组件层级、间距、状态表现和轻量动效，但不得改变功能点、按钮文案、菜单文案、Tooltip、交互语义或页面拓扑。

## 任务

请为现有 Courtside（篮球高光视频助手）生成一套桌面端 UI 重设计方案。

这是一个已经有真实功能的 Flutter macOS/Windows 工具，不是从零设计的营销网站。必须优先保证功能真相和工作流连续性。

## 产品初衷

用户导入固定机位篮球比赛视频，应用在本地分析疑似投篮/进球候选，用户在审核工作台快速播放、保留、排除、调整和导出。产品目标是节省整场观看时间，同时把最终决定权留给用户。

核心产品句：

> 把整场比赛，变成你的高光。

产品承诺：本地处理、原始视频不会被复制或上传；算法生成候选，不把候选包装成自动事实。

## 设计主题

**Quiet Courtside Control Room（安静的场边控制室）**

关键词：video-first、dense but calm、precise、keyboard-friendly、low-noise、macOS desktop utility。

视觉必须像可长时间使用的视频审核工作台，而不是广告页面。深色工作台、清晰的 1px 分隔、低饱和语义色、稳定的时间码、紧凑但可读的候选行。

## 绝对保留的页面拓扑

固定四页，导航顺序不能改变：

1. `项目`
2. `导入`
3. `审核`
4. `导出`

宽窗口保留侧栏 + 顶部条；窄窗口保留顶部条 + 底部导航。

审核页必须保留：

```text
视频工作区（左/主区域） | 候选片段栏（右/独立滚动）
视频下方：播放控制 + 当前候选证据/编辑操作
```

窄窗口变为视频在上、候选在下，不得横向溢出。

### 全局壳必须同时提供的两种宽窗口状态

Stitch 不能只输出一个固定宽度的展开侧栏：

- **展开态**：显示 `Courtside` 品牌、图标和文字导航；
- **收缩态**：保留品牌图标和导航图标，隐藏文字；悬停显示对应 Tooltip；
- 展开态收缩按钮 Tooltip：`收缩侧栏`；
- 收缩态展开按钮 Tooltip：`展开侧栏`；
- 宽度不足时可以自动进入收缩态，但不能删除侧栏功能；
- 需要展示展开/收缩后的当前页面选中态，且内容区不能横向溢出；
- 侧栏收缩/展开只改变视觉密度，不改变四个页面和底部工具项。

禁止新增：

- 左侧额外导航；
- 新的审核流程页；
- 额外的“确认审核/保存审核/下一步”步骤；
- 营销 Hero、统计 Dashboard、云端上传模块；
- 把常规球员选择、保留、排除改成居中弹框。
- `New session` / `New Session`（产品入口名称是 `新建项目`，不是 session）；
- `Settings`、`Dashboard`、英文替代导航或未定义的额外侧栏入口；
- 导入页独立的 `打开输出目录`，打开目录只属于导出页的导出历史能力；
- 审核页未定义的 `SORT` / `排序`入口；候选筛选必须使用 `筛选候选` 和既定筛选项。

## 必须保留的全局功能

### 顶部条和侧栏

保留：

- `项目`、`导入`、`审核`、`导出`；
- Engine 状态：`Engine 就绪`、`等待 Engine`、`Engine 未启动`、`Engine 错误`；
- `关闭当前项目`；
- `本地处理`；
- `更多`菜单：`反馈`、`关于 Courtside`；
- `切换主题`：跟随系统/浅色/深色；
- 侧栏底部 `反馈`、`关于` 和 `本地处理`。
- 侧栏展开态和收缩态都必须被设计稿明确展示或说明，不能默认为永远展开或永远收缩；
- 顶部 `更多` 只能展开 `反馈`、`关于 Courtside`；不能以 `settings` 图标代替 `切换主题`，也不能增加设置页。

### 项目页

必须保留以下文案和操作：

- `把整场比赛，变成你的高光。`
- `导入固定机位视频，本地分析候选进球，剔除误检后导出集锦。所有处理在本机完成，原始视频不会被复制或上传。`
- `从视频开始`
- `新建项目`
- `打开项目`
- `当前项目`、`当前保留`、`已排除`、`视频时长`
- `最近项目`
- `刷新最近项目`
- `删除项目`
- 空状态：`还没有项目`、`新建项目`

删除项目弹框必须保留：

- `删除项目？`
- `将删除“{项目名}”的项目数据库、分析缓存和导出文件，原始视频不会被删除。`
- `取消`、`删除项目`

项目页对照重点：

- `最近项目`必须同时表达项目名、视频名、保留数、候选数、视频时长；只展示“最后修改时间”不足以替代这些业务信息；
- `刷新最近项目`必须有 Tooltip；
- 空状态、加载骨架、加载失败和删除弹框属于页面状态，不得只展示有数据静态态；
- `工作流`可以优化视觉，但不能被改造成新的 Dashboard 或营销统计模块。

### 导入页

保留四步：

- `选择视频`
- `分析范围`
- `检测区域`
- `确认并分析`

保留按钮：

- `选择视频`
- `更换视频`
- `上一步`
- `下一步`
- `确认配置并开始分析`
- `使用全片`
- `投篮分析区`
- `篮网检测区`
- `重置篮网区`

保留状态和弹框：

- `检测到上次未完成的配置。`
- `放弃草稿`、`继续配置`
- 大视频弹框：`这个视频可能需要较长时间`、`先取消`、`继续导入`
- 已有候选弹框：`应用新配置？`、`取消`、`应用并重新分析`
- 视频空状态：`选择原始视频`、`支持 MP4、MOV、M4V、AVI、MKV。原始视频不会被修改或上传。`
- 视频就绪：`视频已准备好`
- 自动识别：`正在自动识别篮筐…`

分析模式必须保留：

- `标准分析`
- `快速分析`
- `快速分析使用低规格代理，可能漏检少量片段。`
- 预计耗时：`开始前预计耗时：约 X–Y 分钟`
- `实际耗时会受视频编码、磁盘和设备负载影响。`

快速模式可以通过轻量开关控制是否展示，但不能删掉文案、风险语义或模式选择能力。

导入页对照重点：

- 页面是四步向导，不是“左侧固定工具栏 + 右侧配置面板”的新工作流；四步必须能映射到现有 `上一步`、`下一步` 和回退逻辑；
- `更换视频`必须位于已有视频状态下，不能被替换成 `打开输出目录`；
- `分析范围`必须有时间轴、播放/暂停、范围两端、当前时间和 `使用全片`；
- `检测区域`必须有自动推荐、`投篮分析区`/`篮网检测区`切换、`重置篮网区`、缩小/放大/适应画面及相应 Tooltip；
- 自动检测中、预览不可用、草稿恢复、大视频提醒和已有候选确认都必须有对应状态，不得只展示静态 ROI 示例；
- 快速/标准模式属于最后一步配置，不能做成顶部全局英文导航。

### 审核页

必须保留：

- 分析状态：`正在分析视频`、阶段、百分比、已用时间、剩余估算；
- `取消`、`重试分析`、`重新分析`；
- 完成摘要：`标准分析 · {N} 个候选 · 用时 {时长}`；
- 快速模式摘要：`快速分析 · 可能漏检 · {N} 个候选 · 用时 {时长}`；
- 视频源切换、视频加载状态、`重新加载视频`；
- 候选播放、暂停、进度条、速度、循环、重播、上一个/下一个；
- 候选标题：`候选片段`；
- 计数：`已选 {N} / {N}`；
- `批量选择候选`、`退出批量选择`；
- `筛选候选`；
- 筛选项：`全部候选`、`待审核`、`已确认`、`已排除`、`低置信度`；
- 快捷键帮助；
- 每行缩略图、序号、事件时间、片段起止时间、实际时长、球员标签、状态和操作按钮；
- `保留片段 (C / Enter)`；
- `排除片段 (X / Backspace)`；
- 底部主按钮：`导出 {N} 个片段`；
- `重新配置分析区域和范围`；
- `重新分析当前视频`；
- 当前候选证据：候选时间、片段范围、时长、备注、置信度、轨迹穿框、篮网运动、反弹判断、系统说明；
- `调整片段范围`、`编辑备注`、`撤销上一次审核 (Cmd/Ctrl+Z)`。

审核页对照重点：

- 宽窗口和窄窗口必须分别审查；窄窗口必须是“顶部条 + 视频/控件 + 候选列表 + 底部导航”，不能只缩放桌面三栏；
- 候选行必须显示真实片段起止时间和实际时长，不能只显示事件时间、文件名或一个缩略图角标时长；
- 候选状态应表达默认保留、待审核、已确认、已排除和低置信度；按钮 Tooltip 仍需保留；
- `筛选候选`不能被英文 `FILTER` 替代；不得加入 `SORT`/排序功能，除非先更新功能真相文档；
- 必须补齐批量选择、快捷键帮助、球员行内锚定菜单、补漏候选、候选备注、调整片段范围和按状态区分的空状态；
- 视频控件必须位于视频下方，进度条必须是可交互时间轴，不得只用静态 scrubber 装饰；
- 当前候选证据条必须表达候选时间、片段范围、时长、备注、置信度、轨迹穿框、篮网运动、反弹判断和系统说明；
- 常规保留/排除不能改成中心弹框，导出后审核仍必须可编辑。

候选默认保留。点击保留/排除不能改变当前选中的候选。排除是状态变化，不是删除。

快捷键必须保持：

| 快捷键 | 动作 |
|---|---|
| `Space` | 播放/暂停 |
| `↑ / ↓` | 切换候选 |
| `← / →` | 快退/快进 2 秒 |
| `R` | 重播 |
| `L` | 循环 |
| `A` | 显示/关闭标注 |
| `C` / `Enter` | 保留 |
| `X` / `Backspace` | 排除 |
| `Cmd/Ctrl+Z` | 撤销 |

球员标签必须使用靠近标签的锚定菜单：

- `搜索球员`
- `未标记`
- 已有球员
- `新建球员`

添加球员弹框：

- `添加球员`
- `例如：科比、罗斯`
- `取消`、`添加`

片段范围弹框：

- `调整片段范围`
- `拖动时间轴两端即可调整。视频会跳到正在拖动的一端；原视频不会被修改。`
- `恢复默认`、`取消`、`应用`

备注弹框：

- `候选备注`
- `例如：补篮、擦框、镜头遮挡`
- `取消`、`保存`

重新分析弹框：

- `重新分析当前视频？`
- `取消`、`重新分析`
- 快速模式建议切标准时保留 `用标准模式重新分析`

必须保留空状态：

- `正在恢复项目`
- `项目数据加载失败`
- `正在等待候选片段`
- `没有匹配的候选`
- `快速分析未找到候选 · 可能漏检`
- `还没有分析结果`

必须保留补漏候选：从原视频当前播放位置加入片段，调整范围后默认保留并可导出。

### 导出页

保留：

- `导出集锦`
- `分析结果默认保留，导出时只排除你打叉的片段。`
- `当前保留`
- `合计时长`
- `输出编码`：`H.264 / AAC`
- `处理方式`：`硬件编码优先，软件回退`
- `导出范围`
- `全部球员`
- 球员筛选
- `未标记`
- `当前筛选：{N} 个 · {时长}`
- 快速模式风险提示及 `关闭提示`
- `合并导出`
- `分别导出`
- 合并导出选择文件名，建议 `highlights.mp4`
- 分别导出选择目录，确认按钮 `选择输出目录`
- 导出阶段：`准备导出`、`生成片段`、`合并片段`、`保存导出记录`
- `取消导出`
- `重试导出`
- `返回审核`
- `最近导出`
- `打开目录`
- 空状态：`还没有导出记录`

导出历史打开目录失败弹框：

- `无法打开目录`
- 目录路径 + 系统错误信息
- `知道了`

导出页对照重点：

- `导出范围`必须是按球员筛选，而不是新增导出配置体系；
- `输出编码`和`处理方式`属于当前固定摘要能力，不能未经需求确认扩展为新的编码设置页面；
- 导出中必须显示阶段、百分比、取消；导出中返回审核后仍能修改候选；
- 最近导出必须显示路径、片段数、时长、创建时间、处理耗时、文件大小、分辨率、视频编码和音频编码；
- `打开目录`只保留在最近导出区域，并处理失败弹框；
- 不能用英文 `Completed`、`Engine: Ready` 等替换当前中文状态文案。

## 交互和动效约束

### 可以优化

- 间距、对齐、层级、边框、背景层级、状态颜色、文字权重；
- 候选行的时间码/时长可扫描性；
- 选中、悬停、焦点、禁用、加载和错误状态；
- 进度条和状态切换的轻量过渡；
- 菜单锚定位置和打开/关闭过渡；
- 侧栏展开/收缩过渡；
- 步骤切换的短暂淡入。

### 不可以改变

- 页面数量和路由顺序；
- 任何文案、按钮、Tooltip 和快捷键语义；
- 候选默认保留的产品规则；
- 视频区 + 候选区的审核大布局；
- 球员选择的行内锚定菜单；
- 导出前后审核可继续修改；
- 本地处理和原始视频不上传的承诺。

### 动效上限

- 普通过渡 150–250ms；
- 不使用连续循环的装饰动画；
- 不自动播放高分辨率视频作为背景；
- 不让动画改变列表行高度或造成按钮移动；
- 尊重 reduced motion。

## Stitch 输出格式要求

请输出：

1. Home、Import、Review、Export 四个桌面页面；
2. 宽窗口和窄窗口的关键状态；
3. 所有本文档列出的弹框和球员锚定菜单；
4. 分析中、分析失败、无候选、快速模式风险、导出中、导出完成、导出失败等关键状态；
5. 每个页面标注保留的功能点和交互，不只输出截图；
6. 为状态变化提供轻量动效说明；
7. 明确列出没有新增或删除的功能。

最终设计应该让当前工程的维护者可以逐项映射到现有 Flutter 组件，而不是要求重写业务流程。
