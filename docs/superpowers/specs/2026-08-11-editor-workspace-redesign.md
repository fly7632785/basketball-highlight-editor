# Courtside 全页面编辑器工作台重构设计

## 目标

在不改变现有本地项目、Python Engine、SQLite、分析、审核和导出业务行为的前提下，将 Flutter 桌面端从“通用后台页面”重构为专业视频编辑器工作台。

目标平台为 macOS / Windows 桌面端，最小窗口 `1180×720`；移动端不纳入本次 UI 实现。

## 已确认的问题

- 当前页面由大量独立卡片、标题和说明文字堆叠而成，缺少视频剪辑软件的工作区层级。
- 审核页把候选放在竖直列表，视频、候选、证据、快捷键说明互相抢空间；用户最常用的视频预览没有成为视觉中心。
- 项目、导入、导出页使用同一套“标题 + 表单卡片”结构，无法表达各自的任务重点。
- 纯黑大背景和大面积空白会放大组件稀疏感；系统色和图标替换不能解决结构问题。

## 不变项

- 保留路由：`/`、`/import`、`/review`、`/export`。
- 保留 `ProjectNotifier` 的项目打开、删除、视频选择、ROI 保存、分析、审核、片段调整、导出等调用。
- 保留全部审核快捷键、候选默认保留逻辑、原视频播放、标注开关和审核记录。
- 不改 Python Engine、SQLite Schema、网络行为、视频文件或用户素材。
- 不新增大型 UI 框架或设计库；仅使用现有 Flutter / Riverpod / media_kit / Cupertino Icons。

## 全局工作区

### 外壳

- 左侧保留可折叠导航，但改为 `60px` 工具栏式导航；展开态仅在项目库需要浏览目录时使用。
- 取消每一页重复的大标题栏。顶部仅保留 `40px` 上下文工具栏：当前工作区、当前项目名、后台任务状态、必要的全局操作。
- 工作区背景使用冷灰黑而非纯黑；视频画布为唯一纯黑区域。
- `#0F1115` 为工作区底色、`#181B21` 为面板、`#232730` 为悬浮/选中面板；蓝色只用于可执行主操作。

### 组件规则

- 不再把每块信息都包进 `CsCard`；只有可浮动的检查器、模态框、媒体条目才有表面。
- 使用 `12px` / `16px` 两级圆角；避免同页面出现多个不同的厚边框。
- 信息标签为 11–12px，数据为 13–14px，页面标题最多 22px；不使用营销式大标题与口号。
- 状态通过图标、文字、色彩三者共同表达；操作按钮至少 `44px` 高。

## 页面设计

### 1. 项目库（`/`）

目的：快速打开或新建一个视频项目，而不是展示仪表盘。

```text
[ 项目库                         + 新建项目  打开项目 ]
[ 最近使用                                              ]
[ 视频缩略图 | 项目名 / 源视频 | 时长  候选  已保留 | ⋯ ]
[ 视频缩略图 | 项目名 / 源视频 | 时长  候选  已保留 | ⋯ ]
```

- 用紧凑媒体行替代大面积卡片和工作流步骤条。
- 行内显示缩略图（已有预览时使用；否则显示低噪声视频占位）、项目名、源视频、时长、候选和保留数。
- 删除操作收进行尾 `⋯` 菜单，不抢占列表主操作。
- 当前打开的项目以轻量选中态显示，可直接跳转回审核。

### 2. 导入与校准（`/import`）

目的：让用户在画面旁完成所有设置，避免上下滚动的表单。

```text
[ 导入视频 / 项目名                              开始分析 ]
[                                                        ]
[  原视频与 ROI 画布                  |  设置检查器     ]
[  可拖拽 / 缩放 / 切换投篮区与篮网区  |  视频信息       ]
[                                     |  分析范围       ]
[                                     |  校准区域说明   ]
[                                     |  自动保存状态   ]
```

- 宽屏为“画布 + 右侧检查器”；窄于 `1180px` 时检查器移动至画布下方。
- 视频选择、分析范围、ROI 与篮网 ROI 均保留原功能和自动保存；只改变呈现位置。
- `开始分析` 固定在顶部右侧，分析不可用时以清晰原因替代隐式禁用。

### 3. 审核工作台（`/review`，本次核心）

目的：以最低成本逐个确认/排除候选，视频始终优先。

```text
[ 视频名                         候选 12 / 50    导出 42 个 ]
[                                                              ]
[                 原视频画布 + 轨迹 / 篮网标注                 ]
[                   播放、循环、前后候选控制                   ]
[--------------------------------------------------------------]
[ ← 候选胶片带：封面 / 时间 / 时长 / 已选状态，可横向滚动 → ]
[ 当前候选  04:10  12.0 秒 | 检测摘要 | 保留        排除   ]
```

- **主画布**：占工作区最大可用高度，播放原视频；控制条叠加或紧贴画布底部，不再通过外层卡片压缩视频。
- **候选胶片带**：替换右侧竖直候选列表。每项为真实预览封面、时间和时长；当前项居中，高亮但不扩大布局。按上下键或点击切换。
- **当前候选检查器**：置于胶片带下方的单行/两行检查器，展示判断、轨迹穿框、篮网、反弹、备注和片段范围入口；详情仅在用户展开时出现。
- **审核操作**：保留/排除固定在右下，两个同等可见的 `52×44px` 按钮；操作不触发候选重选或整页闪动。
- **分析状态**：分析进度显示为顶部不阻断状态条；没有候选时给出“调整区域 / 重新分析”的下一步，而不是空面板。
- `?` 打开快捷键浮层，默认不占页面空间。

### 4. 导出（`/export`）

目的：确认输出而不是填写后台表单。

```text
[ 导出集锦                                                ]
[ 42 个片段 · 08:31 · 原始质量                              ]
[ 合并成一个视频                              分别导出     ]
[ 输出位置 / 最近一次导出                                  ]
```

- 用一个紧凑摘要面板显示数量、总时长、编码和输出位置。
- “合并导出”为主操作，“分别导出”为次操作；进度替换按钮区域而不是再嵌套进卡片。
- 导出记录继续存在，改成紧凑媒体行，可直接打开目录。

## 实施边界与组件拆分

1. `CsWorkspaceShell`：桌面工具栏、导航和页面内容槽。
2. `ReviewWorkspace`：视频画布、浮动控制条、候选胶片带、当前候选检查器。
3. `ImportWorkspace`：视频画布和校准检查器。
4. `MediaProjectRow` / `CandidateFilmstripItem` / `InspectorSection`：只负责视觉与事件回调，不读取业务状态。
5. 状态选择、视频播放、Engine 调用继续由现有页面状态和 Provider 承担。

## 验收标准

- 审核窗口 `1440×900` 下，视频画布高度不低于工作区高度的 60%，且不存在竖直候选大面板。
- 候选缩略项可点击、可用快捷键切换，保留/排除、备注、调整范围、标注开关、循环播放全部回归可用。
- 导入不需要为调整 ROI 在长表单中滚动；导出仍支持合并/分别导出、取消、重试、历史打开目录。
- 项目库、导入、审核、导出在 1180px 宽与 1440px 宽不溢出。
- `flutter analyze`、全量 `flutter test`、`flutter build macos --debug` 通过。
