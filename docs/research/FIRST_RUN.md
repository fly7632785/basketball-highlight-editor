# 首次真实视频基线

## 输入视频

```text
文件：data/videos/飞书20260804-170744.mp4
时长：277.67 秒
分辨率：960×720
视频帧率：30 FPS
场景：固定机位、单篮筐、室外球场
```

## 使用配置

```text
模型：third_party/basketball-shot-detection/bball_model.pt
模型类别：ball / hoop
执行设备：Apple M1 Pro MPS
检测 ROI：x=390, y=180, x2=560, y2=390
ROI 放大：4 倍
采样：5 FPS
置信度阈值：0.15
```

## 实测结果

| 指标 | 结果 |
|---|---:|
| 采样帧数 | 1,389 |
| 检测扫描耗时 | 48.47 秒 |
| 视频时长 / 扫描耗时 | 约 5.7 倍 |
| 含篮球检测的采样帧 | 171 |
| 含篮筐检测的采样帧 | 1,313 |
| 初始几何候选数 | 11 |
| 模型加载时间 | 未计入扫描耗时 |

当前机器本地扫描已经证明可行：**4 分 37 秒的视频可以在 M1 Pro 上以明显快于视频时长的速度完成检测**。这只是单个视频、单个模型和单组参数的基线，不代表最终产品性能。

## 当前判断

- `bball_model.pt` 在这段视频上可以识别 `hoop` 和部分 `ball`，可以继续验证；
- 篮筐在原画面中约 19×23 像素，属于小目标，ROI 放大不是可有可无的优化；
- 现有模型输出足以生成候选，但**尚未有人工标准答案，因此不能计算 Precision、Recall、F1**；
- 11 个候选只是初始几何规则结果，不等于 11 个真实进球；
- 目前没有遇到必须训练模型的证据。

## 下一步

请人工查看上述 11 个时间点附近的片段，补充：

1. 哪些候选是真进球；
2. 哪些候选是未进球、擦筐或其他误报；
3. 视频中是否存在算法完全没有提取出来的真实进球。

完成标注后，才能进入参数调整和模型横向比较。
