# 候选二次精筛结果

## 本轮改动

粗扫仍使用现成 `bball_model.pt`，但对每个候选点回到原视频做 ±1.5 秒、30 FPS 精扫，并新增：

- 置信度下限 `0.25`；
- 轨迹上方至少连续两次观测；
- 上方到下方最长间隔 `0.8 秒`；
- 下降速度至少 `60 px/s`；
- 篮筐横向余量从 `16px` 收紧到 `5px`；
- 水平位移/垂直下降比不超过 `1.2`；
- 篮筐下方至少两次观测；
- 穿越后短时间内不能重新回到篮筐上方。

## 第二版针对性修正

新增：

- 穿越后延长到 1.2 秒观察；
- 检测穿越后的向上反弹；
- 检测球在篮筐下方过早横向离开；
- 保留高召回粗候选，避免只靠单次穿越直接判定。
