# 候选二次精筛结果

## 本轮改动

粗扫仍使用现成 `bball_model.pt`，但对每个候选点回到原视频做 ±1.5 秒、30 FPS 精扫，并新增：

- 置信度下限 `0.25`；
- 轨迹上方至少连续两次观测；
- 上方到下方最长间隔 `0.8 秒`；
- 下降速度至少 `60 px/s`；
- 篮筐横向余量从 `16px` 收紧到 `5px`；
- 水平位移/垂直下降比不超过 `1.2`；
- 篮筐下方至少两次观测；
- 穿越后短时间内不能重新回到篮筐上方。

## 结果

```text
粗候选：11 个
精筛保留：3 个
精筛耗时：22.66 秒
```

保留的候选时间：

```text
12.70s

```

这 3 个仍然只是**算法保留候选，不等于已经确认进球**。精筛提高了候选纯度，但如果规则过严，也可能漏掉真实进球，因此必须同时复核被过滤的 8 个片段。

## 下一步判断

用户需要确认：

1. 3 个精筛候选是否是真进球；
2. 被过滤的 8 个中是否有真实进球；
3. 如果精筛保留的 3 个全是真进球，可继续收紧为产品默认路径；
4. 如果被过滤片段中有真实进球，需要降低某个阈值或加入篮网/音频辅助信号。
