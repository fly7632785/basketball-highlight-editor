# 下一阶段研究与 MVP 计划

## 阶段 1：建立真实数据基线

1. 准备 3～5 段固定机位原始视频。
2. 标注每个真实进球的原始时间戳。
3. 在 `bball-highlights` 的算法思路上建立本地基线。
4. 输出所有候选事件和调试帧。
5. 计算 precision、recall、F1，并记录误报/漏报原因。

## 阶段 2：建立自己的分析接口

输入：

```json
{
  "video_path": "...",
  "rim": {"x": 0, "y": 0, "width": 0, "height": 0},
  "sample_fps": 15
}
```

输出：

```json
{
  "events": [
    {
      "time": 128.42,
      "confidence": 0.82,
      "start": 122.42,
      "end": 131.42,
      "status": "pending"
    }
  ]
}
```

## 阶段 3：审核和导出 MVP

- 候选列表；
- 预览；
- 保留/删除；
- 起止时间调整；
- 单独导出；
- 按时间顺序合并导出；
- 项目恢复。

## 复用策略

先复用 `bball-highlights` 的检测和验证思想，不直接复制代码；先用真实数据证明它适合我们的视频，再决定哪些函数值得提取或重写。
