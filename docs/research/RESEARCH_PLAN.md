# 第三方方案复用调研计划

## 目标

最大程度复用 GitHub 上已有的篮球进球识别和视频集锦代码，避免重复实现已经验证过的检测、轨迹判断、缓存、评估和 FFmpeg 导出逻辑。

## 研究范围

1. 篮球、篮筐检测方式
2. 篮球轨迹关联与进球几何判断
3. 固定篮筐校准流程
4. 长视频扫描、跳帧和缓存
5. 进球候选片段生成和合并
6. 精度评估与人工标注
7. FFmpeg 截取和导出
8. 许可证、依赖和跨平台可移植性

## 复用原则

- 保留第三方仓库原始代码，不在 `third_party/` 内直接修改。
- 优先复用可独立提取的算法和数据结构，不直接复制完整应用。
- 未明确许可证的仓库只做技术参考，不直接纳入产品代码。
- 任何纳入产品的代码都需要记录来源、许可证和改动范围。
- 先用真实视频验证效果，再决定 Python、C++ 或 Rust 的生产实现。

## 研究输出

- `REUSE_MATRIX.md`：模块级复用判断
- `FINDINGS.md`：算法、工程和许可证结论
- `NEXT_PLAN.md`：下一阶段 MVP 计划
