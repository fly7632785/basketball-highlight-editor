# Product screenshots

This page collects the main screens so that new users can understand the workflow at a glance. The screenshots come from local demo footage, and copy or layout may change between versions.

## 1. Project home

Start here: create or open a project, then follow “import video → set ROI → analyze → review → export”.

![Project home](../capture/screenshot-20260813-145724.png)

## 2. Import a video

Choose the original game video. The source is referenced locally and is not copied or uploaded by default.

![Import video](../capture/screenshot-20260813-145741.png)

## 3. Set the analysis range

Limit the part of the video to analyze before continuing to hoop-region setup and analysis.

![Analysis range](../capture/screenshot-20260813-145806.png)

## 4. Review candidates

The review workbench keeps the source video, candidate list, and clip details together. You can play, switch candidates, keep, exclude, or adjust a range.

![Review workbench](../capture/screenshot-20260813-161507.png)

## 5. Export highlights

When review is done, merge the kept candidates into one reel or export them as separate clips.

![Export highlights](../capture/screenshot-20260813-161649.png)
