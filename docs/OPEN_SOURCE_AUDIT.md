# 开源公开前审计记录

更新时间：2026-08-18

## 当前公开策略

第一阶段发布源码预览版，目标是让开发者理解架构并在本地准备依赖后运行。当前不承诺提供可直接安装的 macOS/Windows 发布包。

## 已处理

- 增加 MIT 许可证和第三方声明入口；
- 移除研究仓库 gitlink，避免把本地研究 checkout 作为主项目源码分发；
- 移除包含本机路径的研发标注 CSV；
- 移除尚未确认授权的模型权重；
- 移除实际内容为 HTML 页面而非字体文件的 `.ttf` 资源；
- 增加本地数据、模型和运行时产物的忽略规则；
- 移除开发机截屏，只保留 `capture/README.md` 的本地素材说明；
- 增加开源预检脚本、贡献规范和安全报告入口。

## 仍需在正式 Release 前完成

- 按实际锁定版本生成 Python/Flutter/FFmpeg notices；
- 确认模型权重和训练数据的授权，或提供用户自备模型流程；
- 使用可公开的演示视频和截图替换任何真实素材；
- 在无仓库、无 Homebrew、无开发 `.venv` 的干净机器上验证运行时；
- 完成 macOS 签名、公证和 Windows 安装包验证；
- 确认 GitHub 仓库地址、维护者联系方式和默认分支策略；
- 移动端 CI 等待 `packages/bhe_core` 与移动端变更进入公开分支后再开启。

## 阻塞项定义

以下任一项存在时，不发布二进制或模型附件：

- 未核验的权重或训练数据授权；
- 未处理的本机路径、密钥、个人数据或真实视频；
- 运行时依赖无法在干净机器复现；
- 第三方许可证文本未随发布物提供。
