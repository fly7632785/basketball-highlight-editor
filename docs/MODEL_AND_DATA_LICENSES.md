# 模型与数据授权边界

## 当前结论

公开源码不包含模型权重、训练数据或真实比赛视频。模型目录只保留使用说明，`models/*.pt`、`models/*.onnx`、`models/*.pth` 和 `models/*.bin` 均被 Git 忽略。

## 必须分别核验的对象

1. 模型代码许可证；
2. 模型权重许可证；
3. 训练数据及其衍生数据的授权；
4. Ultralytics、PyTorch、OpenCV 等推理依赖的许可证；
5. 输入视频、球员画面、队伍标识和场馆素材的公开处理权限。

代码仓库的许可证不能自动覆盖模型权重和数据。没有权利证明时，只能要求用户自行准备模型和数据，不应在 Release 中提供下载附件。

## 本地运行约定

```text
models/bball_model.pt
```

模型文件缺失时，运行时检查应明确报告缺失，不应静默下载未知来源的权重。
